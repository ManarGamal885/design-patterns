- RMI (Remote Method Invocation )Registry:
The RMI registry is a small program that helps Java programs talk to each other over a network.

It’s like a helper service that keeps track of which remote objects are available — and where they are.
You have two Java programs:

🖥️ Server — has an object with some useful methods (for example, sayHello()).

💻 Client — wants to use that object, but it’s on another computer.

How can the client find it?

👉 That’s where the RMI registry comes in.
- The RMI registry is a small program that helps a client find the server object that contains the methods the client wants to use.

- What is serialVersionUID?

It’s a unique identifier for a Serializable class.

Java uses it during serialization and deserialization to verify that the class definition matches between sender and receiver.
