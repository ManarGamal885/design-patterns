Aspect                 Inheritance                            Composition
Relationship             "IS-A"                                 "HAS-A"
Coupling         Tight(strongly connected)               Loose(weakly connected)
Flexibility      Hard to change at runtime               Easy to change at runtime
Code Reuse         Through parent class                    Through contained objects
When parent changes  Child automatically changes             Child not affected
